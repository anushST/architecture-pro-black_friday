# pymongo-api

## Как запустить

Запускаем mongodb и приложение

```shell
docker compose up -d
```

Настраиваем и заполняем mongodb данными

```shell
./scripts/mongo-init.sh
```

## Как проверить

### Если вы запускаете проект на локальной машине

Откройте в браузере http://localhost:8080

Для проверки кэширования откройте в браузере http://localhost:8080/helloDoc/users. Повторный вызов должен происходить значительно быстрее чем первый.
